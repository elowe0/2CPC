### Écriture sur le disque
!cards
Commande à coller | La page applique le changement tout de suite (localStorage) et met les actions en file. Un bouton « Appliquer » copie une commande, `cpc.py apply "status a done ; delete b"`, à coller dans un terminal ou dans Claude. | + marche partout (Firefox compris) ; + cohérent avec le copier-coller des réponses ; - une étape manuelle
Accès direct au dossier | API File System Access (Chrome / Edge) : on clique une fois sur « Connecter .2cpc » par session, puis la page écrit `index.json` et déplace les plans supprimés. | + immédiat ; - pas sous Firefox (repli sur la commande) ; - fonctionnement en file:// à valider par un prototype
Mini-serveur local | `cpc.py dash` sert le tableau de bord sur 127.0.0.1 avec une petite API d'écriture | + le plus fluide ; - un processus à lancer ; - écarté pour les réponses en v1
!end

# 2. Icônes pixel art {#icons}
Prototype (stdlib, encodeur PNG maison, grilles 16×16 agrandies ×4 avec contour et ombrage calculés). **Ligne du haut** : créature générée par le hash de l'id seul. **Ligne du bas** : motif choisi selon le sujet (haut-parleur, bouclier, engrenage, maison) ; la couleur et le fond viennent toujours du hash.
!img C:/Users/blackbox/AppData/Local/Temp/claude/a599e41953b40bc1/dfe160e3-b3ab-4591-ab2c-072505a7f9f7/scratchpad/icons/out/sheet.png | Prototype : sons village · consent · build APK · décor village · grappin · tuto
> note: Le coût en tokens se joue sur **qui choisit le motif**. Générer le PNG ne coûte rien : c'est du Python déterministe.

!cards
Hash seul | Créature symétrique tirée de l'id | + 0 token ; + toujours unique ; - aucun lien avec le sujet
Mots-clés automatiques | Le script compare les mots du titre et de l'intro (FR/EN) à une bibliothèque de motifs ; couleur et fond viennent du hash ; à défaut, créature | + 0 token agent ; + lié au sujet ; - bibliothèque à dessiner une fois ; - un mot-clé peut être mal reconnu
Mots-clés + `icon:` | Comme ci-dessus, mais l'agent peut forcer le motif dans l'en-tête (`icon: speaker`, `icon: shield #c33`) | + ≈3–5 tokens seulement quand il le faut ; + corrige les erreurs de mots-clés ; - liste des motifs à connaître (1 ligne dans DSL.md)
Dessin par l'agent | L'agent écrit une grille 16×16 en ASCII dans le plan | + sur mesure ; - ≈200–300 tokens par plan ; - qualité variable
!end
