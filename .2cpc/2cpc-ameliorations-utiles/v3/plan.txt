# P2 — Stockage & todos
!table | Item | Spec
| C1 | Assets copiés une seule fois dans `.2cpc/<id>/assets/<sha8>-<nom>`, référencés en `../assets/…`. Le `rebuild` migre les anciennes versions.
| C3 | `cpc.py gc [<id>] [--keep N]` : supprime les `index.html` des versions plus anciennes que les N dernières (**le `plan.txt` et `answers.txt` sont gardés**), plus les assets orphelins. **Simulation par défaut**, suppression réelle avec `--yes`.
| C4 | En-tête `status: brouillon / actif / fait / archivé` + `cpc.py status <id> fait` (sans nouvelle version). `list` masque `archivé` sauf avec `--all`.
| E1 | `!todo` accepte `KEY=Label`. `cpc.py todo <id> KEY… [--undo]` → `.2cpc/<id>/state.json`. La page affiche ✓ « fait par l'agent » (non décochable) et l'état est reporté en vN+1 par clé.
?approve p2 | Specs P2 | C1=Assets partagés + migration ; C3=`gc` (simulation par défaut, garde plan.txt) ; C4=Statut + commande ; E1=Todos à clés + `cpc.py todo`

# P3 — Navigation & outillage
!table | Item | Spec
| D1 | `.2cpc/index.html` régénéré à chaque `new` / `patch` / `rebuild` : cartes plan → version, date, statut, todos (state.json), dernière réponse enregistrée. L'avancement en direct vient du localStorage si le navigateur le permet (Chrome partage l'origine `file://`, Firefox non).
| D2 | `~/.2cpc/registry.json` (chemins des projets), mis à jour par `new`. `cpc.py list --all` liste les plans de tous les projets ; chemins morts ignorés.
| D3 | Champ de recherche (Ctrl+F interne, surligne et filtre les sections) + bascule « Sans réponse seulement ».
| D4 | Sommaire collant, avec pastille « n restantes » par section et ● si obligatoire manquante.
| F3 | À chaque `new`, comparer le hash du SKILL.md installé au gabarit → `WARN skill outdated: python install.py`.
| F4 | `cpc.py rebuild --all` : rebuild de tous les projets du registre.
?approve p3 | Specs P3 | D1=Tableau de bord ; D2=Registre + `list --all` ; D3=Recherche + filtre ; D4=Sommaire à pastilles ; F3=Check du skill ; F4=`rebuild --all`
